# AI Agents Feature SPA

This project is organized into separate frontend and backend applications.

## Structure

- `frontend/` — React/Vite client, shared UI components, hooks, types, and frontend configuration.
- `backend/` — Express/Mongoose server, controllers, routes, services, models, middleware, configuration, and tests.

## Frontend

```bash
cd frontend
npm install
npm run dev
```

## Backend

```bash
cd backend
npm install
npm run dev
```
